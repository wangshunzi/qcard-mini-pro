# 海洋 / 森林主题重制创意规范

本批次先生成本地候选素材，经确认后已上传 OSS 并替换海洋、森林主题图片配置。

## 通用规则

- 每个主题 9 个页面资源，每个资源提供浅色和暗色版本，共 18 张；两套主题共 36 张。
- 横向页面资源按 16:9 原生构图，组卡页 `gen_bg` 按 9:16 原生构图，登录页按 3:4 原生构图。
- 角色、建筑和高对比装饰必须避开真实 UI 区域；每张图根据所在页面单独设计，禁止只换色或重复同一背景。
- 明暗版本保持页面叙事和主要物体位置相近，但暗色版使用独立的夜间照明、发光元素和材质表达。
- 无文字、数字、徽标、水印、伪按钮、伪卡片或其他伪 UI；不得拉伸人物、动物、建筑和自然物。
- 风格统一为精致、友好、适合儿童学习产品的 3D 绘本插画，细节丰富但不干扰界面可读性。

## 生成提示词结构

本批素材使用内置图像生成模式逐张生成，不是脚本绘图。最终提示词由以下三部分组合：

1. 页面专属场景：采用上表对应的场景、角色、道具和 UI 留位。
2. 统一画风：精致友好的 3D 绘本插画、丰富空间层次、柔和电影光照、儿童产品适配；无文字、数字、徽标、水印、伪 UI。
3. 暗色配对：保持浅色版的场景、机位、角色与主要道具位置，仅改为月光/深海夜景照明，加入克制的生物荧光或萤火虫、暖色局部灯光，保证暗色界面对比度。

森林探索页额外执行了局部清理提示：移除木制罗盘上的伪数字与伪字母，只保留叶片刻度和几何罗盘星。

## 导出规格

| 资源类型 | 输出尺寸 | 处理方式 |
| --- | --- | --- |
| 横向页面背景 | 1280 × 720 | 等比缩放并在不足 1px 时补边，不裁剪、不拉伸 |
| `gen_bg` 组卡页 | 720 × 1280 | 9:16 原生构图，等比缩放，不裁剪、不拉伸 |
| `login_bg` 浅色 | 768 × 1024 | 3:4 原生构图，等比缩放，不裁剪、不拉伸 |
| `login_bg_dark` 暗色 | 864 × 1152 | 3:4 原生构图，等比缩放，不裁剪、不拉伸 |

压缩格式为 JPEG，单张图片约 100–266 KB。36 张图片已逐一通过 OSS 公网大小校验，两个主题的客户端可用主题接口均已返回新版本路径。
