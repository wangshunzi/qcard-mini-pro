# 极地冰川主题：页面化视觉规范

本主题不使用“同一片冰原换角色”的重复构图。每张背景都围绕实际页面叠层设计，并保留明暗模式同构切换。

| 资源 | 页面叙事 | UI 留位 |
| --- | --- | --- |
| `home_bg` | 极地迎宾站与学习航线 | 上方中央欢迎语；下方今日挑战 |
| `explore_bg` | 极地探险营地与发现足迹 | 左上标题、顶部操作、底部搜索 |
| `resource_bg` | 冰晶知识档案馆 | 左上标题、顶部筛选、底部搜索 |
| `profile_bg` | 极地个人营地 | 左中头像与昵称、下方统计和快捷卡片 |
| `learning_bg` | 企鹅学校与卡包站 | 中上标题、底部搜索 |
| `detail_bg` | 冰晶陈列馆 | 顶部导航、中央下方卡包封面 |
| `search_bg` | 极地观测站与足迹侦察 | 搜索和结果信息的主要区域 |
| `gen_bg` | 极光冰雕创作工坊 | 中央双卡预览、下方操作区 |
| `login_bg` | 踏入极地之门 | 顶部品牌标识；表单位于背景之外 |

通用约束：无文字、无数字、无标志、无伪 UI；角色和高对比物体避开文案与操作控件；暗色图与浅色图保持构图一致。

图片适配约束：不修改页面既有的 `cover` / `aspectFill` 展示规则。若素材构图不适配页面，必须重新生成该素材，而不是通过改变展示模式、拉伸或大幅裁切旧图修补。`gen_bg_dark` v4 是为组卡页重新创作的原生 9:16 构图，并无裁剪等比压缩为 720 × 1280。
